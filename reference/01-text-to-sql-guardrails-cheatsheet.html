2. As 3 Camadas de Guardrails para Text-to-SQL

Em ambientes corporativos, confiar apenas que a LLM "prometeu não apagar nada" é vulnerabilidade crítica (OWASP LLM07). A defesa deve ser em profundidade:

Camada 1: Guardrail Léxico & Semântico (Regex / AST)

Valida o texto gerado antes que ele toque qualquer conexão de banco. Permite estritamente declarações SELECT e WITH ... SELECT. Rejeita INSERT, UPDATE, DELETE, DROP, ALTER, TRUNCATE, ATTACH, DETACH, PRAGMA.

Camada 2: Guardrail Operacional (LIMIT e Timeout)

Impede ataques de negação de serviço (DoS) por memória. Se o SQL do agente não tiver cláusula LIMIT, o middleware injeta automaticamente um teto máximo (ex.: LIMIT 100). Impõe timeout rígido de execução (ex.: 5 segundos).

Camada 3: Guardrail de Driver / Infraestrutura (Read-Only)

No nível do conector SQLite, abrir a conexão em URI estritamente de leitura: file:cinerocket.db?mode=ro e aplicar PRAGMA query_only = ON. Mesmo que um atacante consiga burlar o parser de texto, o próprio kernel do SQLite abortará qualquer tentativa de escrita.

3. Anatomia de Mensagens no LangChain Tool Calling

O fluxo de conversação quando um modelo decide chamar ferramentas:

from langchain_core.messages import HumanMessage, AIMessage, ToolMessage

# 1. Usuário envia a pergunta
messages = [HumanMessage(content="Qual o filme mais lucrativo?")]

# 2. LLM responde pedindo a execução de uma tool
response = llm_with_tools.invoke(messages)
# response.tool_calls -> [{'name': 'execute_sql', 'args': {'query': '...'}, 'id': 'call_123'}]
messages.append(response)

# 3. Seu código executa a tool em Python e devolve como ToolMessage
tool_output = execute_sql("SELECT titulo, lucro_brl FROM ... LIMIT 1")
messages.append(ToolMessage(content=str(tool_output), tool_call_id='call_123'))

# 4. LLM recebe o histórico completo e gera a resposta final em linguagem natural
final_response = llm_with_tools.invoke(messages)
print(final_response.content)

4. Mapa Dimensional do CineData (SQLite)

Estrutura das tabelas para junções precisas:

  • Fato Central: fact_movies_performance (chave: sk_movie_id) — métricas de receita_brl, orcamento_brl, lucro_brl, popularidade, nota_tmdb, nota_imdb.
  • Dimensão Filmes: dim_movies (chave: sk_movie_id) — metadados como titulo, ano_lancamento, duracao_minutos, status_filme.
  • Dimensões & Bridges:
    • Gêneros: dim_genres ligada por bridge_movie_genre
    • Pessoas (Atores/Diretores): dim_people ligada por bridge_movie_person (atenção ao campo tipo_pessoa)
    • Produtoras: dim_companies ligada por bridge_movie_company
    • Avaliações: dim_reviews (agregadas) e movie_reviews (comentários textuais)
