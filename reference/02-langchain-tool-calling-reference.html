Guia de Referência #02 LangChain Core

LangChain: Protocolo de Mensagens & Tool Calling

Guia sintático dos blocos fundamentais para orquestração de agentes

1. As 4 Mensagens Fundamentais (`langchain_core.messages`)

Todo agente conversacional no LangChain troca uma lista ordenada de mensagens:

  • SystemMessage: Define a persona, regras, schema linking e restrições éticas/técnicas. É o "cérebro" das instruções.
  • HumanMessage: O input enviado pelo usuário final (ex.: "Quais os filmes de ficção científica mais lucrativos?").
  • AIMessage: A resposta gerada pelo modelo. Pode conter texto final em content ou intenções de chamada em tool_calls.
  • ToolMessage: O resultado produzido pela sua função Python real, devolvido ao modelo com o tool_call_id correspondente.

2. O Decorador `@tool` de `langchain_core.tools`

Transforma qualquer função Python em uma ferramenta estruturada legível pelo modelo:

from langchain_core.tools import tool

@tool
def get_movie_rating(title: str) -> str:
    """Retorna a nota IMDb e TMDB de um filme a partir do título exato.
    
    Args:
        title: O nome do filme a ser pesquisado.
    """
    # Código Python executado localmente na sua máquina
    return f"Nota IMDb de {title}: 8.5"
Regra de Ouro da Docstring

A LLM não lê o código interno da função; ela lê apenas o nome, os tipos dos argumentos e a docstring. Se a docstring for vaga, o agente não saberá quando ou como chamar sua tool.

3. O Loop de Execução de Tool Calling (Sem Mágica)

# 1. Vincular ferramentas ao modelo
llm_with_tools = llm.bind_tools([get_movie_rating, execute_safe_sql])

# 2. Primeira invocação
messages = [
    SystemMessage(content="Você é um assistente analítico."),
    HumanMessage(content="Qual a nota de Inception?")
]
ai_msg = llm_with_tools.invoke(messages)
messages.append(ai_msg)

# 3. Execução das ferramentas solicitadas
if ai_msg.tool_calls:
    for call in ai_msg.tool_calls:
        # call tem: {'name': '...', 'args': {...}, 'id': '...'}
        tool_to_run = tools_by_name[call["name"]]
        output = tool_to_run.invoke(call["args"])
        
        # 4. Empacota a resposta como ToolMessage
        messages.append(ToolMessage(content=str(output), tool_call_id=call["id"]))

# 5. Invocação final com os dados reais
final_response = llm_with_tools.invoke(messages)
print(final_response.content)
